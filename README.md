# FreeLancer
A simple Freelancing Api that uses jwt for authentication 

## Features

- Get, post and update a freelancing profile 
- A secure jwt api application 
- Can produce data in xml and json

## Tech Stack

- Language/Framework: (C#, .NET)
- Database: (Microsoft sql sever)
- Tools: (Git)

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [.NET SDK](https://dotnet.microsoft.com/download)
- You may need to run dotnet restore in the terminal
- And also change the appsettings Connection string
